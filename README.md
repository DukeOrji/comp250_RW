# Mexico - The Perfect Dictatorship

## Overview:
This repository consists of my revised essay, alng with the files used to manage citations and formatting during the revision process.


- `Essay_revision.md` - The revised essay written and maintained in Markdown.
- `cited-items.json` - Contains the bibliographic information for the sources cited in the essay and is used by Pandoc to generate the bibliography.
- `chicago-author-date.csl` - Citation style file used to format the essay using Chicago author-date citations.
- `.gitignore` - Prevents generated DOCX files from being added to the Git repository.


## Original Context:
I initially wrote this essay as a presentation and description of Mexico's Institutional Revolutionary Party (PRI) for my comparative politics course last semester. The essay focused on how the PRI maintained political authority for over 70 years through authoritarian institutions, patronage, elections, and management of its winning coalition. It also examined how these institutions changed over time and contributed to Mexico's democratic transition.

## Revision Process:
I converted the initial essay into a Markdown file
I used Git for version control
I utilized Zotero to organize my sources and Better BibTex to compose citation keys.
Then i connected the bibliography to the Markdown file using a CSL ".Json" file, then used pandoc to generate and check the citations and bibliography.
This project demonstrates my ability to use version control to track modifications in the repository while maintaining a productive workflow for producing a final document.
